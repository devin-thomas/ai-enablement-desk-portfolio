# Demo scripts

## 90-second walkthrough

1. **0:00-0:15 — Problem.** “This desk turns ambiguous AI requests into governed, reviewable records. Everything shown is synthetic.”
2. **0:15-0:30 — Intake.** Reset the demo, select the maintenance request, and point out that queue counts and provider states come from the server.
3. **0:30-0:50 — Analysis.** Run the injected or configured analysis. Contrast confirmed facts, unconfirmed assumptions, and the model suggestion with the deterministic route.
4. **0:50-1:05 — Human gate.** Answer the blocking clarification, re-run analysis, enter the named reviewer and rationale, then approve discovery.
5. **1:05-1:20 — Evidence.** Show request and decision n8n execution IDs, correlation IDs, and the actor-separated audit trail.
6. **1:20-1:30 — Fallback.** Show the written summary as authoritative and explain that audio exists only when real bytes were persisted.

## Three-minute walkthrough

1. **0:00-0:25 — Context and boundaries.** Explain that this is a portfolio vertical slice rather than a production enterprise platform. Show the three synthetic scenarios.
2. **0:25-0:55 — Durable intake.** Submit or reset the maintenance scenario. Refresh the page to demonstrate that the browser is not the source of truth.
3. **0:55-1:30 — Advisory AI.** Run analysis. Show provenance, facts, assumptions, unknowns, questions, model suggestion, and deterministic rule evaluation. Emphasize that schema validation precedes routing.
4. **1:30-2:00 — Clarification and human control.** Save the requested evidence, re-analyze, and record a named approval with rationale. Point out version binding and legal transitions.
5. **2:00-2:25 — Real automation.** Show separate n8n executions for submission and decision, including correlation, workflow version, retry status, and execution ID.
6. **2:25-2:40 — Optional audio.** Play the persisted synthetic briefing if configured; otherwise show the accurate degraded state and unchanged written summary.
7. **2:40-3:00 — Safety proof.** Open the high-risk employee-data scenario. Show the deterministic privacy override and disabled approval. End on the quality command and public-safety documentation.
