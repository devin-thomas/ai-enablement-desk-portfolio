# AED-004 implementation evidence

Status: complete.

## Implemented and locally verified

- Credential-free n8n exports for `request-submitted` and `request-decision-recorded` validate an HMAC signature and return the n8n execution ID.
- Durable automation attempts record workflow version, correlation and idempotency IDs, attempt number, timestamps, external execution ID, and sanitized failures.
- Request creation and committed human decisions dispatch separate webhooks without rolling back the database transaction when delivery fails.
- Bounded retry, idempotency, and accurate success, retrying, failed, disabled, and unavailable states are covered by an HTTP webhook integration stub.
- The replaceable Fish Audio adapter accepts only successful written analyses for explicitly synthetic demo-safe requests and persists only non-empty `audio/*` bytes.
- The reviewer UI shows provider health, execution evidence, retry controls, authoritative written text, and audio controls only for real persisted artifacts.

## Local verification

On 2026-07-30, `npm run typecheck`, `npm test`, and `npm run build` passed. The suite contains 34 tests, including three n8n boundary cases and three audio boundary cases. The committed workflow exports and repository were scanned for common credential patterns with no matches.
